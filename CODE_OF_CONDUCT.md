# Code of Conduct

## Our Pledge

We aim to keep this project welcoming, respectful, and focused on practical collaboration.

## Expected Behavior

- Be respectful and constructive.
- Discuss ideas and code on their merits.
- Assume good intent, but accept corrections when impact differs from intent.
- Keep feedback specific and actionable.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Sharing private information without permission.
- Repeated off-topic disruption.
- Any behavior that makes collaboration unsafe or hostile.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or block participants when behavior violates this code of conduct.

If you need to report a concern, use the repository's available contact channel or open a private security advisory when the issue is security-sensitive.
